Two skills, working together

✍️ social Writes
Drafts platform-tailored copy. LinkedIn long-form, X threads, IG captions, FB posts. Hook-driven, on-brand, no fluff. (coreyhaines31/marketingskills)
📤 social-publisher Ships
Cross-platform publisher. LinkedIn, X, IG, FB, TikTok — one call, schedules or sends now. (claude-office-skills/skills)
Install once: 
npx skills add coreyhaines31/marketingskills --skill social
npx skills add claude-office-skills/skills --skill social-publisher

The full workflow

1
You give a topic "new feature dropped, post about it on LinkedIn + X + IG"
↓
2
social skill drafts copy One version per platform, tone-matched to each
↓
3
image gen produces visual Right aspect ratio per platform — square, wide, vertical
↓
4
social-publisher ships it Schedules or posts now to every connected account
The point: a whole social brand runs from the same chat window. Image, caption, posting — agent does all of it.
Platform Updates

What shipped in May.

Twelve features. One big rebuild. Here's what changed since we last talked.

🧠

Claude Max install

One-click orchestrator for Claude Max as a model provider. SSE-streamed setup flow with session store + stage runner. No CLI gymnastics.

⚙️

Model providers, redesigned

New providers page with Claude Max form, Google built-in, and a manage menu. Add, configure, swap — all from the dashboard.

❤️

Health dashboard

Full redesign: VPS cards, live actions, update dialogs, status chips. Know what your agent is doing without SSH-ing into anything.

🔌

Channels: disconnect & manage

Disconnect, enable, disable any channel from a single menu. No more orphaned integrations sitting in the dark.

💳

Prorated agent seats

AddAgentSeatDialog now shows the daily prorated breakdown. Add a seat mid-cycle, see exactly what you'll be charged.

🧩

Google brain wiring

Pick Google as your brain during onboarding. BrainCredentials flow handles the OAuth + provisioning end-to-end.

🖥️

Terminal, hardened

Graceful broker shutdown + UX error mapping. Terminal sessions no longer die mysteriously when the backend hiccups.

🎨

UI primitives polished

Badge, button, command, dialog, navigation, overlay shell, toggle — all updated. The little things you feel but can't name.
